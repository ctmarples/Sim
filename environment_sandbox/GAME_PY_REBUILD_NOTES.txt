Rebuild checklist for game.py
-----------------------------

1) Fish drawing (_draw_fish)
   - Use wildlife.fish_icon_for(item.kind)
   - Do NOT recolour body (species SVGs keep native colours)

2) Fish biodiversity (_sample_environment)
   - Pass fish_positions=((f.x, f.y, f.kind.name.lower()) for f in self.fish.fish)
   - Also pass wolf_positions=self.wildlife.wolf_positions() (or equivalent)
   - environment.EnvMaps.sample / indicators.biodiversity_snapshot already accept these

3) Wolf drawing (_draw_animals or dedicated helper)
   - Draw each pack member with wolf_male / wolf_female icons
   - Viewport cull + entity_draw_xy (same pattern as deer pairs)
   - Outline members when a wolf pack is selected in management/inspect

4) Wildlife tick (_tick_wildlife)
   - Pass biodiversity=getattr(self.env_maps, "biodiversity", None)
   - Keep hunter_threats= and flee_interval=

5) Threats (_hunt_threat_positions)
   - Player + ALL villagers (not only assigned hunters)
   - Deer/boar/wolves flee these; prey also flee wolf positions inside wildlife

6) Flee interval (_hunter_flee_interval)
   - Read balance ANIMAL_FLEE_SECONDS_AT_X1 via seconds_to_ticks
   - Do not use plain villager walk ticks alone

7) Wildlife management list (_wildlife_management_rows)
   - Return 5-tuples: (kind, id, title, subtitle, inhabited: bool)
   - Include wolf packs as AnimalKind.WOLF (or stable kind token management expects)
   - inhabited=False for empty deer/boar grounds and empty bee/rabbit nests
   - management_window filters on wildlife_inhabited_only + wildlife_species

8) Select / inspect wolves
   - Handle habitat list hit for WOLF / wolf_pack id
   - Build HabitatInspectView with panel_kind="wolf":
       activity, last_meal, food_status (days left), fed_until,
       pack size/sexes, hunt capability, health, breed chance, location/bio
   - Use pack.food_days_left(day) / fed_days_remaining (not year-wrap fed_until_day math)
   - Mirror selection into management.select_habitat

9) Player + fisher catch (already mostly restored)
   - kill_fish returns (x, y, FishKind)
   - yield via fish_yield_for(kind)
   - Fisher: gate on can_add(1) then filter catchable by fish_yield_for(f.kind);
     if add fails after kill, shore-deposit instead of losing fish
   - Delivery when holding fish and cannot fit FISH_YIELD (max species)

10) Imports
   - From wildlife as needed: fish_icon_for, fish_yield_for, FishKind, AnimalKind.WOLF
   - Icons: wolf_male, wolf_female already in icons.py
